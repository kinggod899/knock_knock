# knock knock 邀约

绝区零一条龙（ZenlessZoneZero-OneDragon）插件：代你向代理人发送约会邀请，每天三次。

插件先传送到录像店，按 Q 唤出 knock knock，再逐个代你向代理人发送约会邀请，把对话走完、时段选好。开跑前会先把昨天遗留的过期邀约点掉，不然第二天会被卡在会话页。

## 装什么

- 绝区零一条龙 **2.0.0 或更高**
- 只在 Windows 上跑
- 必须用一条龙启动器启动：游戏进程是提权的，非管理员进程发的键鼠事件会被 Windows 挡掉

## 它做什么

开跑顺序：

1. 传送到「录像店-房间」。knock knock 只能在录像店范围内开。
2. 按 **Q** 唤出界面，切到中间的「会话」页。
3. 清掉会话里带红色感叹号的**过期邀约**（昨天约了没赴约留下的）。
4. 切到左边「联系人」页，从一个代理人开始往下走：
   - 状态「在线」→ 点「邀约」；
   - 状态「联络中」→ 今天约过了，跳过；
   - 弹出「信赖等阶已满」→ 按配置点取消或确认；
   - 弹出「信赖已到达当前等阶满值」→ 点取消，换下一个（点「前往」会跑出邀约流程）。
5. 进了对话就反复点白色选项条，直到出结束界面。
   - 「开始邀约同行」→ 直接点；
   - 「上午/下午/夜晚/凌晨 + 加入日程」→ 四个时段依次全点一遍，再点「加入日程」。
6. 邀请发出去后回列表继续下一个，直到做满配置的次数。
7. 弹出「今天邀约次数已用完」→ 点确认、关界面、收工。

**按流程走完就算成功**：结束界面出来、该点的都点过，这次约会邀请就算发出去了。左上角「剩余邀约 N/3」不参与判定 —— 它只在联系人页读得到，读不到时会返回 -1，拿来判成功会误判。它只用于「显示已经是 0/3 就提前收工」。

## 设置

在一条龙的应用卡片上点齿轮，改这两项：

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 尝试邀约次数 | 5 | 一天最多点几次「邀约」。成功上限固定是 3 次；这个数设得比 3 大，是为了跨过信赖全满、卡着升阶任务那些点不动的代理人 |
| 达到信赖后继续骚扰代理人 | 关 | 关着：信赖满级弹窗点「取消」换人；开着：点「确认」继续邀约（拿不到更多信赖值，但流程能走完） |

配置存在 `config/<实例>/<分组>/knock_knock.yml`。

## 跑之前要确认

- 用一条龙启动器运行（它自带提权）。用非提权的 Python 直接跑，游戏不会有任何反应。
- 游戏窗口在屏幕上可见。插件会把游戏窗口拉到前台，键鼠事件只作用在前台窗口。
- 游戏语言是简体中文。所有判据都靠中文 OCR 和中文界面坐标。

## 目录结构

```
knock_knock/
├── plugin.json          插件市场用的元数据
├── knock_knock/         插件包，目录名 = APP_ID
│   ├── const.py         应用身份
│   ├── factory.py       工厂
│   ├── app.py           状态机，15 个节点
│   ├── screen.py        画面坐标与颜色标定值
│   ├── config.py        配置项
│   ├── app_setting.py   设置入口声明
│   └── setting_flyout.py 设置弹窗
├── docs/                开发文档（画面建档、交接日志）
└── scripts/             本地校验与打包脚本
```

## 本地校验与打包

```shell
python scripts/validate_plugin.py --strict
python scripts/build_zip.py
```
